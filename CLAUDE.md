# GRADE rewrite

Read these in order before you change anything:
1. `docs/progress.md` - what is done, what comes next, how to run the checks.
2. `architecture.md` - the plan. Sections 0-2 first, then the milestone you work on (section 9).
3. `docs/decisions.md` - small decisions made while you build.

## Accepted differences from architecture.md
Do not stop and flag these. The user accepted them, and `docs/decisions.md` gives the reasons.
- `Analysis` has an extra optional `structure` field (section kind and similarity per section).
- Tier is calculated in `packages/core` (`programFromAnalysis`), not in the Python analyzer.
- Silence trim uses `level` (RMS divided by its maximum), not the min-max energy curve.
- Fixtures are synthetic songs, generated by `apps/server/tests/fixtures/synth.py`.

If you find a new difference, add one line to `docs/decisions.md`.
